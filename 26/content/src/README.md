# 校对源文件（26 版）

这里每个 `.md` 对应网站的一节。只改文字，保留标记；改完在站点根目录运行：

```powershell
python tools/build_content.py
```

## 规则

- `# s02 资本主义与政治经济学`：节标题，`s02` 是节 id，不要改。
- `part: 马原`：属于哪个部分（对应 `parts.md`）。
- `## 020 资本主义的新变化-二战后`：卡片编号 + 标题，编号不要改。
- `- [0] 文字`：一行正文；`[0]/[1]/[2]` 是缩进级别，`[0+]` 表示这一行前留空隙。
- `{{b|文字}}`：给文字上色：
  - `b` 浅蓝、`n` 深蓝、`r` 红、`o` 橙、`g` 绿、`p` 紫、`d` 深灰、`m` 浅灰、`k` 黑。
- 不写标记就是深灰。
- 26 版的 emoji 是 PDF 文字里的 Unicode 字符，直接写 `✅`、`⚠`、`❶` 即可，不要改成 `{{e|...}}`。
- 旗帜 emoji 在 Windows 会显示成 `CN/RU/LR`，所以源文件里已经处理：`🇷🇺`→`俄`、`🇱🇷`→`利`，`🇨🇳` 直接去掉（原文已有「中国」）；不要再写旗帜。
- `page: 4`：PDF 页码，用于目录和「书上第 N 页起」。

只改文字时，保留标记：

```text
- [0] {{b|马克思和恩格斯建立的}}{{r|第一个无产阶级政党}}{{b|：}}
```

想整行换掉、不要颜色：

```text
- [0] 马克思和恩格斯建立了第一个无产阶级政党。
```

## 定位

