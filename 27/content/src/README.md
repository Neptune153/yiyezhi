# 校对源文件

这里每个 `.md` 对应网站的一节，直接改文字即可，改完在本文件夹运行：

```powershell
python tools/build_content.py
```

## 规则

- `# s02 资本主义及垄断`：节标题，`s02` 是节 id，不要改。
- `part: 马原`：属于哪个部分（对应 `parts.md`）。
- `## 014 资本主义的新变化-二战后`：知识点编号 + 标题，编号不要改。
- `- [0] 文字`：一行正文，`[0]/[1]/[2]` 是缩进级别，`[0+]` 表示这一行前留空隙。
- `{{b|文字}}`：给文字上色，`b` 蓝、`n` 深蓝、`r` 红、`o` 橙、`g` 绿、`p` 紫、`d` 深灰、`m` 浅灰、`k` 黑；不写标记就是正文默认深灰。
- `{{e|62}}`：emoji 图片，数字是 `content/emoji/62.png` 的编号；不建议手改。
- `page: 5`：书上页码，用于目录和“书上第 N 页起”。

页面上每张卡右上角有「定位」，点一下会复制「文件名 + 行号」，直接跳过去改就行。

只改文字时，保留标记即可，例如：

```text
- [0] {{b|马克思和恩格斯建立的}}{{o|第一个无产阶级政党}}{{b|：}}
```

如果只想整行换掉、不要颜色，直接写：

```text
- [0] 马克思和恩格斯建立了第一个无产阶级政党。
```
